 # Energy-Aware Path Planning in 2D and 3D Environment

This project presents an interactive simulation system for intelligent robot navigation in both 2D and 3D environments using the A* path planning algorithm. The system generates obstacle-based grid maps and computes an optimal path between user-defined start and goal positions.

The project also includes optimized path smoothing, candidate path generation, dynamic obstacle handling, real-time robot simulation, and 3D terrain visualization. Users can visualize robot movement directly on the grid map and analyze the performance of different path planning strategies using comparison graphs.

The application is developed using Python and Streamlit with visualization support from Matplotlib and Plotly, providing an intuitive and interactive user interface for robotics and path planning research.



## Features

- A* Path Planning
- Optimized Path Planning
- Candidate Path Generation
- 3D Terrain Visualization
- Dynamic Obstacles
- Real-Time Robot Simulation
- Performance Comparison Dashboard

## Technologies

- Python
- Streamlit
- NumPy
- Matplotlib
- Plotly
- Pandas
